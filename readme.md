# Resume and Skill Gap Analyzer

A Streamlit-based application that analyzes resumes and compares candidate skills against job roles.

## Features
- Upload PDF resumes
- Extract skills automatically
- Compare skills with selected job roles
- Calculate match percentage
- Identify missing skills

## Tech Stack
- Python
- Streamlit
- Pandas
- PDFPlumber

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
